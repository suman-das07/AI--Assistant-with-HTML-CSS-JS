# 🤖 AI Assistant with HTML, CSS & JavaScript

An interactive AI-powered virtual assistant built using pure HTML, CSS, and JavaScript. The project provides a modern chatbot-style interface with animations, voice visuals, and responsive design.

---

# 🌐 Live Demo

🔗 https://suman-das07.github.io/AI--Assistant-with-HTML-CSS-JS/

# 📌 Features

* 💬 Interactive AI assistant UI
* 🎤 Voice assistant animations
* 🎨 Modern responsive design
* ⚡ Smooth loading animations
* 📱 Mobile-friendly interface
* 🔥 Lightweight frontend project
* 🧠 JavaScript-based assistant logic
* 🎥 Integrated video and GIF assets

# 🚀 How to Run the Project

## Run Locally

1. Clone the repository

```
git clone https://github.com/suman-das07/AI--Assistant-with-HTML-CSS-JS.git
```

2. Open the project folder

```
cd AI--Assistant-with-HTML-CSS-JS
```

3. Run the project

Open `index.html` in your browser.
